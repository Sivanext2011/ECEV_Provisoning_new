Classic EC → CBEV Subscriber Migration — Developer Handbook

Audience: engineering Status: implementation spec Vendor-neutral

This handbook specifies what a production-grade migration service must do and why. The migration/ Python package in this repository is a working proof-of-concept and the reference design; it is not the deliverable. Code snippets are illustrative, not prescriptive — re-implement in any stack with HA, throughput, observability and rollback guarantees designed in.

How to read: §1–4 are mandatory background (domain, contracts, state model). §5–9 are the per-stage specs you implement. §10–16 cover the production concerns the PoC only partially addresses and that you MUST harden. §17–20 are reference appendices.
